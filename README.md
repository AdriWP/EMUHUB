# EMUHUB

A native Windows game launcher (Python + PySide6/Qt6) for the Switch and 3DS emulators of your choice.

**The program starts completely empty and in English.** There are no preset emulators – you add your own emulators, games, music and colors (the language can be switched to German in Settings). **No** games, ROMs, keys, firmware or emulators are included.

## Features
- Tile grid with covers, hover zoom, search, filters, favorites, sorting, adjustable tile size
- Launch with a double-click, with custom launch arguments per game or per emulator
- **Add and set up your own emulators** (name, color, program, default arguments) – Settings → Emulators
- **Custom themes** with a color picker, background image
- **Background music** (MP3 and more) and a **bubble hover sound effect**, each with a volume slider (applied instantly)
- Screenshot gallery per game
- Controller support (Xbox / PlayStation / Switch Pro)
- German and English interface

## Installation
Requirements: Windows and [Python](https://www.python.org/downloads/) 3.10 or newer (when installing, tick "Add python.exe to PATH" or install the `py` launcher).

```
py -m pip install -r emu_launcher/requirements.txt
```

## Run
Double-click `emu_launcher/main.pyw` (no console window) – or run:

```
py emu_launcher/main.py
```

On first start EMUHUB creates the file `games_data.json` and the folder `covers/` next to the program (`backgrounds/` follows when you choose a background image).
These are **your personal data** (games, paths, settings). They stay on your computer and are intentionally not part of this repository.

## As an .exe (no Python needed)
Download the ZIP from "Releases", extract it and run `EMUHUB.exe` – Python is not required.
To build it yourself: double-click `build_exe.bat` (Python required); the result is in `dist\EMUHUB`. Share the **whole folder**.
Windows or antivirus software sometimes warns about unknown .exe files – this is normal for self-built programs.

## Getting started
1. **Settings → Emulators → "＋ Add emulator":** enter a name, pick a color and choose the emulator's program (.exe). "Search automatically" finds it by name.
2. **"+ Add game":** choose a ROM file, the emulator and optionally a cover.
3. **Settings → Design / Music & Sound:** theme, background, music and volumes to your liking.

## Troubleshooting
- **No music or sound effect:** make sure the full `PySide6` package is installed (it includes Qt Multimedia) – run the pip command above again.
- **Controller not detected:** install `pygame-ce` (part of `requirements.txt`); the launcher works without it, just without controller support.
- **Crash or blank window:** see `emu_launcher/emuhub_error.log` (next to the program).

## Notes
- EMUHUB is only a launcher. Graphics, controllers, firmware and keys are configured in the emulator itself (button "Open emulator").
- You need the rights to the games you launch (your own backups). This project contains and distributes no copyrighted content.
- All emulator and console names belong to their respective owners. EMUHUB is not affiliated with them.
- Logo, icon and sound were generated by the project itself (`tools/make_brand_assets.py`, `tools/make_sounds.py`).
